How I work a defect

Guessing is expensive on a production platform. I'd rather spend an hour proving the cause than a week shipping fixes for the wrong one.

Reproduce or refute

Background scripts against real data in dev. If it won't reproduce, that's a finding too.

Read the history

sys_audit, sysevent, syslog and Script Tracer — what fired, in what order, and what didn't.

Name the line

A case-sensitive compare. A return inside a loop. A missing guard. The cause is always specific.

Verify by simulation

Run the corrected logic against the affected record before touching code. Numbers must match.

Fix, then repair

Code fix through update sets, then a scoped backfill with setWorkflow(false) and a sign-off.
